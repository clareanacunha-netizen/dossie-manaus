# Dossiê de Manaus

Site estático com o material fornecido pela autora, organizado para leitura e edição. Não precisa instalar programas nem executar comandos para alterar o conteúdo pelo GitHub.

**Endereço previsto após a publicação:** https://clareanacunha-netizen.github.io/dossie-manaus/

## Quero alterar o dossiê

Comece pelo [guia de edição](COMO-EDITAR.md). Para mudar um texto, abra `index.html` no GitHub, clique no lápis, faça a alteração e escolha **Commit changes** para salvar. A publicação leva algum tempo depois de salvar.

## Arquivos

| Arquivo | O que contém |
| --- | --- |
| `index.html` | Textos, tabelas, gráficos e links exibidos na página |
| `assets/styles.css` | Cores, tamanhos e aparência |
| `assets/script.js` | Comportamentos da página |
| `dados/manaus-linha-do-tempo.csv` | Dados da linha do tempo |
| `dados/manaus-graficos.csv` | Dados dos gráficos |
| `dados/manaus-fontes.csv` | Referências do dossiê |
| `.nojekyll` | Mantém a publicação direta dos arquivos no GitHub Pages |

Os CSVs são arquivos de apoio: **alterá-los não atualiza a página automaticamente**. Ao mudar números, atualize também as tabelas, barras e textos correspondentes em `index.html`.

## Publicação

O site usa GitHub Pages, com a branch `main` e a pasta `/(root)`, sem etapa de compilação. Essa seleção fica em **Settings → Pages**. Também é possível abrir `index.html` no computador para consultar a página localmente.

## Fontes e atualização

O conteúdo parte do material fornecido pela autora; esta preparação para publicação não inclui nova apuração jornalística. Preserve as referências e confira a fonte antes de atualizar informações. As datas de edição escritas no dossiê precisam ser alteradas manualmente.
